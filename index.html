AI Reference LibraryFaces 1,499 · Poses 288 / 1,439 images · Outfits 1,407 sets

  • Workflow: pick a face to lock in "who she is" → pick a pose from the Poses library → pick an outfit from the Outfits library → hand the three reference images plus one instruction to the model.
  • Too lazy to pick? The default view is "Random combo": it draws a face / outfit / pose in one go and generates a ready-made prompt (including source links to the three images) that you can copy and hand to another agent.
  • Example instruction: change the pose of the character in image 1 to the pose in image 2, and swap the clothes for the outfit in image 3; keep the face, hairstyle, body type, lighting and art style unchanged. The modal has a "Copy prompt" button that includes the ID and category automatically.
  • Why images instead of text: describing poses and outfits in words always drifts (the same sentence gives a different number of folds, length and limb angles each time); reference images stay stable.
  • This repo contains thumbnails only: "Download original" jumps to the matching file on the author's source site (open it in a new tab and save it). Please do not repackage and redistribute the originals.
